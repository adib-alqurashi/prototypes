# Prototypes

Small things I build to scratch an itch: Obsidian plugins, browser extensions, scripts and tools. Each one lives in its own folder with a README that says what it does, how to install it and how to make it better. Nothing here is a product; everything here works.

| Prototype | What it is | Status |
| --- | --- | --- |
| [obsidian/study-timer](obsidian/study-timer/) | Obsidian plugin: one-click study timer, stats card, and a month calendar of dated tasks | In daily use |

## Layout

```
obsidian/      Obsidian plugins
extensions/    Browser extensions
tools/         Scripts and command-line tools
```

A prototype's folder has at least a `README.md` with: what it does, install, use, how it works, ideas for improving it, what I learned.

## Contributing

Issues and pull requests are welcome on any prototype. Each README ends with a list of improvements that are open; pick one, or propose your own in an issue first so we don't do the same work twice. Keep a change to one prototype per pull request.
